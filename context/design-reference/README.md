# Design References

These files are implementation references, not runtime web assets. Keeping them under `context/` prevents Next.js and OpenNext from publishing them from `public/`.

`homepage.png` is the permanent shared visual authority defined by `AGENTS.md` and `context/ui-system.md`. Feature-specific mockups should be retained only while they remain approved, current, and explicitly referenced by project context.

Generated browser captures and visual-comparison output belong under `artifacts/` and are intentionally ignored by Git.
